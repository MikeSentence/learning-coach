MCP（模型上下文协议，Model Context Protocol）：完整形态需要跑本地或远程服务进程。本页是纯前端单文件，不启动进程、也不执行工具调用循环；这里登记的是远程 HTTP 端点与能力声明，只作为「可用知识来源」注入提示词，让模型出题 / 判卷时参考。浏览器直连外部端点还受跨源资源共享（Cross-Origin Resource Sharing，CORS）限制；要真正跑工具循环，需要支持 MCP 的网关或代理。
端点 Token 只存这台设备的浏览器，不进提示词、不进导出文件。
