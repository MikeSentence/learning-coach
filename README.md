# learning-coach

闯关式学习教练：把「我想学 X」变成一条不用自己设计的学习路线。

## 打开

浏览器直接打开根目录的 `index.html` 就行，单文件、零依赖、不用装 Node、不用起服务。

在线版（GitHub Pages，与 `main` 分支同步）：https://mikesentence.github.io/learning-coach/

## 能做什么

- 填任意主题，自动拆成 4-6 关，一次只问一题
- 三种内容来源：接自己的模型现编题目、自练模式（通用自检追问链，不编造学科事实）、内置中性示例包
  - AI 教练：接口地址与模型名默认预填 DeepSeek（`https://api.deepseek.com/v1` / `deepseek-flash`），**只需填自己的 API Key**；模型可换 `deepseek-v4-pro`，接口可改任意 OpenAI 兼容服务
  - 配置**按键即落盘**（不等防抖），单独存一份：刷新页面、换主题、清空学习数据、导入学习包、多标签同时打开都不会丢；老版本存档首次打开会自动迁移
  - 「测一下连通」在设置里显示实际请求地址、模型名、Key 脱敏指纹与具体失败原因（401 / 402 / 404 / 超时 / 被安全策略拦截等）
  - 密钥只存在浏览器本地，不写进仓库、不写进导出的学习记录
- 六种题型混搭、难度自适应、常驻进度条、术语全称对照、薄弱点间隔复习
  - 题型由每关的能力目标决定：概念辨析多出选择 / 判断，机制拆解多出填空 / 手撕，场景判断多出场景题，不机械轮换
  - 判断题给「正确 / 错误」两个选项，另要求写理由；每题都带思路提示（hint）和可选补充信息（extra），不再像冷冰冰的考试
- **题目可回看**：同一关里做第 2 题时，点题号能回看第 1 题的题干、你的答案、正确答案和解析；回看只是换视图，不改动当前进度
- **图解讲解**：铺垫支持 1-2 页，每页可内嵌一张图；展示区支持时序图、关系 / 概念图、流程图、步骤链路、数形结合曲线和对照表，全部用内联 SVG / HTML 绘制，零依赖
- **术语浮窗**：贴着触发按钮弹出，可拖动；标题栏「▾」收起成圆形按钮（带术语条数角标），点按钮原位展开。术语表可滚动、可搜索；顶栏「📖 术语」和题目下方入口都能打开。术语与对话浮窗可同时打开
- **随堂对话**：顶栏「💬 问教练」和每题下方的「💬 就这题问教练」打开对话浮窗，同样贴着按钮弹出、可拖动、可收起成圆形按钮（带消息数角标）；默认上下文是当前关卡 + 当前题目（铺垫、术语、题干、选项、你正在写的答案）；按关卡分别保存对话，换题不丢。对话只发给你在设置里配置的接口，不经过其他服务
- **进度可点**：点顶栏进度条打开进度总览（各关状态、正确率、跳转按钮），点左侧关卡地图上的圆点直接跳关。已学过的关回去会停在原来的位置（题目或结算页），跳到没学过的关会先确认一次
- **语音**：顶栏 🔊 朗读当前这一屏、再点停止；🎤 语音作答，把说的话填进答案框。设置里可调语速、开「换题自动朗读」。用的是浏览器原生的语音合成（Text To Speech，TTS）和语音识别（Automatic Speech Recognition，ASR），零依赖、不经过配置的 AI 接口、不上传学习记录
  - 朗读在 Edge / Chrome 可用；中文语音由系统提供，部分系统语音本身需要联网加载
  - 语音输入需要麦克风权限，且依赖浏览器厂商的在线识别服务，国内网络下不保证可用；`file://` 打开时可能被禁，优先用在线 https 地址
- **生成进度条**：AI 拆路线、逐关出题、重新讲解、AI 判卷时，顶栏出现非阻塞进度条（阶段名 + n/N + 百分比），**全程不遮挡题目页面**；路线页还能「预生成全部关卡题目」，一次把后面几关备好
- **四拍随时回看**：铺垫 / 展示 / 检验 / 结算都能点开，进入答题后照样能回头看铺垫、图表和实时成绩。回看只是换视图，不改变真实进度与答题状态，一键回到当前
- **开放题 AI 判卷**：场景题 / 反问题 / 手撕题交卷后，可让模型按判定要点给出 `ok / 半懂 / 没答上`、分数、点评与更好的答法；结果只是建议，可「采纳」也可继续自己判
- **Skills / MCP 自定义**：设置里「能力扩展」可增删改启停教学技能与远程 MCP 知识源，自动保存、可导出导入，「预览注入内容」能看到实际发出的 system 提示词
- 记录存在浏览器本地，可导出 Markdown / JSON，换设备能导回来接着学
- 多主题历史：开新主题时自动把上一份存成快照，顶栏「历史主题」里可恢复 / 导出 / 删除 / 整体备份。快照不含密钥，全程无需数据库

## 关于 Skills / MCP 的边界

- **Skills（技能）**：一段可复用的教学指令，直接拼进 system 提示词，影响出题风格与判定口径。内置 5 个模板（费曼式讲解、先类比后公式、苏格拉底追问、备考冲刺、错题回炉），可自由改、可停用。
- **MCP（模型上下文协议，Model Context Protocol）**：完整形态需要跑本地或远程服务进程。本页是纯前端单文件，**不启动进程、也不执行工具调用循环**；这里登记的是远程 HTTP 端点与能力声明，只作为「可用知识来源」写进提示词，让模型出题 / 判卷时参考，并明确禁止伪造来自这些来源的查询结果。浏览器直连外部端点还受跨源资源共享（Cross-Origin Resource Sharing，CORS）限制，真要跑工具循环需要支持 MCP 的网关或代理。
- 生成关卡与题目时 Skills + MCP 都注入；开放题判卷只注入 MCP（避免教学技能把判卷带偏）；「测一下连通」不注入任何扩展。
- API Key 与 MCP Token 只存本机浏览器（`localStorage` 里独立的配置项），**不进提示词、不进任何导出文件**；导出的能力配置会剔除 Token。多标签之间会互相同步，若写入失败（无痕模式 / 空间满）会明确提示「刷新可能丢」，不会静默失败。
